# Личный помощник поиска работы

Локальный кабинет: «Обзор», «Нужен твой ответ», «Настройки».

- Поиск аналитических вакансий и персональные отклики.
- API модели (router.cheap / DeepSeek / OpenAI) классифицирует сообщения и готовит ответы с учётом резюме, вакансии и переписки.
- Благодарности, отказы и информационные сообщения не требуют ответа. Каждый ответ HR отправляется только после проверки и нажатия пользователем.
- Ключи сохраняются через Windows DPAPI; в Linux — через Fernet с HH_MASTER_KEY. Секреты, база и profile.json исключены из Git.
- Новые сообщения перед отправкой, неопределённая доставка и дубликаты проверяются отдельно. При капче работа приостанавливается для пользователя.

## Локальный запуск

1. Python 3.11+, Node.js 18+. Установить `npm install` и `npx playwright install chromium`.
2. Скопировать `profile.example.json` в `profile.json`, заполнить реальные факты резюме. Для личного существующего проекта файл уже заполнен и хранится вне Git.
3. `python app.py --no-open`, открыть http://127.0.0.1:8765/.
4. В настройках добавить ссылку на резюме, критерии и модель. Ключ вставлять только в защищённое поле кабинета, не в исходники. Для router.cheap идентификатор модели выбирается из доступных аккаунту `/v1/models`.
5. «Проверить API» делает короткий платный запрос без резюме. «Подготовить ответы с AI» использует сохранённую переписку; «Обновить сообщения» получает свежие чаты и затем готовит ответы. Одинаковый контекст кэшируется.

Текст резюме можно обновить в настройках без редактирования исходников. Технические вопросы модель раскрывает по существу, а неподтверждённые личные факты не должны превращаться в выдуманный опыт. Финальная проверка перед отправкой обязательна.

## Проверки

`python -m unittest discover -s tests`

Браузерные тесты с перехваченными запросами: `node tests/chats.test.cjs`, `node tests/browser.test.cjs`, `node tests/questionnaire.test.cjs`.

## Размещение

См. [DEPLOY_RENDER.md](DEPLOY_RENDER.md). Dockerfile и render.yaml подготовлены. Для Render Free подготовлен Postgres в Supabase и зашифрованное сохранение браузерного сеанса. Бесплатный сервер засыпает; круглосуточная работа не обещается. Внешний доступ требует HTTPS и HH_ACCESS_PASSWORD. Интерфейс не выставляется наружу без защиты.

Отклики и чаты пока зависят от браузерного сеанса. Для облака подготовлено защищённое окно noVNC для входа/MFA/CAPTCHA. Сборка и потребление памяти бесплатного сервиса должны быть проверены на Render. Telegram Mini App и Supabase пока не подключены.
