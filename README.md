# HH Assistant

Локальный Windows-помощник для поиска вакансий аналитика на hh.ru: подбор, сопроводительные письма, отклики и работа с чатами через браузер Playwright.

## Запуск из исходников

1. Установите Python 3.11+ и Node.js 20+.
2. Скопируйте `profile.example.json` в `profile.json`, заполните только достоверные факты о себе. Не включайте автоматические действия с примером профиля.
3. Запустите `Установить.cmd` для установки Playwright и Chromium.
4. Запустите `Запустить.vbs` или `python launch.py`. Интерфейс: http://127.0.0.1:8765.
5. В разделе подключения войдите в hh.ru в отдельном окне браузера и выберите резюме. Настройте фильтры и включите нужные действия.

Автоматические действия по умолчанию выключены. Для работы нужны включённый ПК и интернет. При первом запуске требуется вход в hh.ru. Программа использует обычные страницы сайта; их изменения могут требовать обновления адаптера.

## Поведение

- Аналитические роли, явно отмеченные «Без опыта»; офис/гибрид в Москве или удалённая работа.
- Минимум 60 000 ₽ на руки, цель 70 000 ₽; вакансии без зарплаты допустимы.
- Aston / Астон исключён. Правило находится в `excluded_employer` в `app.py`.
- Готовая очередь откликов обрабатывается до повторного полного поиска, небольшими партиями с проверкой чатов.
- Уже существующие и неподтверждённые отклики автоматически не повторяются.
- Мониторинг чатов ограничен подтверждёнными откликами помощника; старая переписка не импортируется в работу.
- Ответы на анкеты берутся из профиля и настроек. Неизвестные вопросы передаются пользователю; даты интервью и сроки тестовых согласуются с ним.
- История, сеанс браузера и настройки сохраняются локально в `data/`.

## Проверки

```powershell
python -m unittest discover -s tests
npm run test:browser
npm run test:chats
npm run test:questionnaire
```

Браузерные тесты используют фиктивные страницы с перехватом запросов; реальные отклики не отправляют.

## Сборка Windows

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --windowed --onedir --name HHAssistant launch.py
```

Скопируйте `HHAssistant.exe` и `_internal` из `dist/HHAssistant` в папку приложения, рядом с интерфейсом, `profile.json`, браузерными модулями и `node_modules`. Установленный Node.js должен быть доступен через PATH либо указан в локальном `runtime.json`. Папку сборки нужно хранить целиком.

## Личные данные

`profile.json`, `data/`, cookies, токены, настройки среды, исполняемые файлы и зависимости исключены из Git. Репозиторий содержит только исходники, шаблон профиля и синтетические тестовые данные. Не добавляйте файлы из этих исключений принудительно.
