НАСТРОЕНО ПОД ТЕБЯ

Настройки

Резюме, критерии подбора и модель для ответов.

Резюме и пожелания

Черновики используют сохранённый профиль. Замена ссылки выбирает резюме для откликов; для новых фактов нужно обновить контекст ниже.

Критерии подбора

Где: офис и гибрид в Москве, удалёнка по России.

Опыт: без опыта или 1–3 года.

Доход: вакансии без зарплаты тоже рассматриваются.

Исключения: Aston, старшие и руководящие позиции.

Как работает автоматический поиск

«Найти и откликнуться» запускает один подбор и отправку подходящих откликов. «Запустить» на главной включает повторную проверку новых вакансий.

Между откликами — пауза не меньше двух минут. При капче работа приостанавливается. Ответы HR отправляются только после твоего нажатия.

Применяются к следующему подбору

Модель для ответов HR

Не подключена

API модели определяет, нужен ли ответ, и готовит его по переписке, вакансии и резюме. Ключ хранится на сервере; в сообщения HR он не попадает.

При включении модели выбранному провайдеру передаются текст резюме и контекст переписки для подготовки черновика. Запросы расходуют баланс API.

Подключение hh.ru

API поиска hh.ru и API модели — разные подключения. Сейчас отправка откликов и чтение чатов используют отдельный сеанс браузера. Необходимость входа появится здесь.
